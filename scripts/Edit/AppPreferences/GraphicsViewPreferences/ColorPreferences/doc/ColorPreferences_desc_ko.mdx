배경색과 십자선 색상 등 그래픽 뷰에서 사용되는 색상에 대한 응용 프로그램 환경설정 페이지입니다.

#### 선택

*기본 선택 색상*

선택한 엔티티를 강조 표시하는 색상입니다.

*선택한 엔티티를 후광으로 강조 표시*

이 확인란을 선택하면 선택한 엔티티가 고유 색상으로 표시되고 그 뒤에 기본 선택 색상의 흐릿한 후광이 표시됩니다. 마우스 커서 아래의 엔티티는 해당 색상의 더 밝거나 더 어두운 색조의 후광으로 강조 표시됩니다. 확인란을 선택 해제하면 선택한 엔티티가 기본 선택 색상으로 표시됩니다.

*후광 크기 (px)*

선택한 엔티티 주위의 후광 너비(픽셀)입니다.
